## 논문정보

> **High-Dimensional Continuous Control Using Generalized Advantage Estimation**  
> John Schulman et al. (UC Berkeley)  
> ICLR 2016 · [Paper](https://arxiv.org/abs/1506.02438)

## 배경
parameterized stochastic policy에서 total return의 기댓값을 사용하면 policy의 gradient의 불편추정량을 얻을 수 있습니다.
하지만 gradient의 분산이 커지는 문제점이 있었습니다.

actor-critic방식을 이용하면 경험적으로 얻어지는 return이 아니라 value function을 사용합니다. value function을 사용하는 것은
분산은 낮지만 편향이 발생하게 됩니다.

높은 분산은 더 많은 샘플을 요구하고 편향은 성능에 해롭습니다. 이 때 advantage를 학습에 사용하면 가장 낮은 분산을 얻을 수 있습니다. 그러나 advantage function은 직접 알 수 없고 추정을 해야합니다. 논문에서는 Generalized Advantage Estimator(GAE)라는 
방식으로 advantage function을 추정합니다. 

## GAE
GAE를 통해 어떻게 advantage를 추정하는지 알아보겠습니다.
논문에서 나오는 수식 부분을 중점적으로 따라가겠습니다.

policy gradient는 다음과 같이 나타낼 수 있습니다.

$$
g=\mathbb{E}\left[\sum_{t=0}^{\infty}\Psi_t\nabla_\theta\log\pi_\theta(a_t,s_t)\right]
$$

여기서 $\Psi$는 6가지의 경우가 있습니다.
1. total reward of the trajectory.
2. rewards following action $a_t$.
3. baselined version of previous formula
4. state-action value function
5. advantage function
6. TD residual

이 6가지 경우중에서 advantage function을 택하는 경우가 가장 낮은 분산을 만들어낸다고 합니다.

### $\gamma-just$
$\gamma$는 지연된 보상에 낮은 가중치를 부여하여 분산을 낮추는데 사용됩니다. 그러나 그 대가로 편향을 만들어냅니다.
이는 discounted MDP에서의 discount factor와 같지만 undiscounted problem에서 분산을 줄이는 파라미터로 간주하고 사용하게 됩니다.

discounted value function들은 다음과 같습니다.

$$
\begin{align}
V^{\pi,\gamma}(s_t) &:= \mathbb{E}_{s_{t+1:\infty},\, a_{t:\infty}} \left[ \sum_{l=0}^{\infty} \gamma^{l} r_{t+l} \right] \\
Q^{\pi,\gamma}(s_t, a_t) &:= \mathbb{E}_{s_{t+1:\infty},\, a_{t+1:\infty}} \left[ \sum_{l=0}^{\infty} \gamma^{l} r_{t+l} \right] \\
A^{\pi,\gamma}(s_t, a_t) &:= Q^{\pi,\gamma}(s_t, a_t) - V^{\pi,\gamma}(s_t)
\end{align}
$$

discounted approximation to the policy gradient는 다음과 같습니다.

$$
g^{\gamma} := \mathbb{E}_{s_{0:\infty},\, a_{0:\infty}} \left[ \sum_{t=0}^{\infty} A^{\pi,\gamma}(s_t, a_t)\, \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]
$$

advantage estimator $\hat{A}_t$는 다음과 같은 조건을 만족시키면 γ-just라 합니다.

$$
\mathbb{E}_{s_{0:\infty},\, a_{0:\infty}} \left[ \hat{A}_t(s_{0:\infty}, a_{0:\infty})\, \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]
= \mathbb{E}_{s_{0:\infty},\, a_{0:\infty}} \left[ A^{\pi,\gamma}(s_t, a_t)\, \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]
$$

즉 $\hat{A}_t$로 gradient의 기댓값을 구했을 때 $A^{\pi,\gamma}$를 사용했을 때의 gradient의 기댓값과 같다면 γ-just라 부릅니다.

**Proposition 1** $\hat{A}_t$가 다음과 같은 형태이면 γ-just입니다.

$$\hat{A}(s_{0:\infty},a_{0:\infty})=Q_t(s_{t:\infty},a_{t:\infty})-b_t(s_{0:t},a_{0:t-1})$$

γ-just의 예시는 다음과 같습니다.

- $\sum_{l=0}^{\infty} \gamma^{l} r_{t+l}$
- $Q^{\pi,\gamma}(s_t, a_t)$
- $A^{\pi,\gamma}(s_t, a_t)$
- $r_t + \gamma V^{\pi,\gamma}(s_{t+1}) - V^{\pi,\gamma}(s_t)$

### Advantage Function Estimation
$V$를 approximate value function이라고 하면 $\delta_t^V$는 다음과 같이 정의됩니다. $\delta_t^V=r_t+\gamma V(s_{t+1})-V(s_t)$.
$\delta_t^V$는 $a_t$에 대한 advantage 추정량이라고 할 수 있습니다. 만약 $V=V^{\pi,\gamma}$라면 이는 γ-just advantage estimator가 됩니다. 그렇지 않으면 이로 추정한 gradient는 biased gradient가 됩니다.

$t$ 시점부터 $k$개의 TD 잔차 $\delta$를 $\gamma$로 할인하여 더한 값을 $\hat{A}_t^{(k)}$라고 정의합니다.

$$
\begin{align}
\hat{A}_t^{(1)} &:= \delta_t^V = -V(s_t) + r_t + \gamma V(s_{t+1}) \\
\hat{A}_t^{(2)} &:= \delta_t^V + \gamma \delta_{t+1}^V = -V(s_t) + r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) \\
\hat{A}_t^{(3)} &:= \delta_t^V + \gamma \delta_{t+1}^V + \gamma^2 \delta_{t+2}^V = -V(s_t) + r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \gamma^3 V(s_{t+3}) \\
\hat{A}_t^{(k)} &:= \sum_{l=0}^{k-1} \gamma^l \delta_{t+l}^V = -V(s_t) + r_t + \gamma r_{t+1} + \cdots + \gamma^{k-1} r_{t+k-1} + \gamma^k V(s_{t+k})
\end{align}
$$

telescoping sum을 이용하여 위와 같은 결과를 얻을 수 있습니다. $V=V^{\pi,\gamma}$일 때만 γ-just이지만 k가 커질 수록
$\gamma^k V(s_{t+k})$가 작아지므로 bias가 작아집니다. k를 무한대까지 키우면 다음과 같습니다.

$$\hat{A}_t^{(\infty)} = \sum_{l=0}^{\infty} \gamma^l \delta_{t+l}^V = -V(s_t) + \sum_{l=0}^{\infty} \gamma^l r_{t+l}$$

emprical return에서 value function을 baseline으로 뺀 식을 얻습니다.

generalized advantage estimator $GAE(\gamma,\lambda)$는 다음과 같이 지수 가중 평균을 이용해 정의됩니다.

$$
\begin{align}
\hat{A}_t^{\mathrm{GAE}(\gamma,\lambda)} &:= (1-\lambda)\left(\hat{A}_t^{(1)} + \lambda \hat{A}_t^{(2)} + \lambda^2 \hat{A}_t^{(3)} + \cdots\right) \\
&= \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l}^V
\end{align}
$$

최종 식은 무한 등비급수의 합 공식을 이용하면 얻을 수 있습니다.

## Interpretation as Rewards Shaping
transformed reward $\widetilde{r}$을 다음과 같이 정의합니다.

$$\widetilde{r}(s,a,s')=r(s,a,s')+\gamma\Psi(s')-\Psi(s)$$

$\Psi$는 임의의 state space에 대한 sclar-valued function입니다.

이렇게 reward를 변형하는 것은 $A^{\pi,\gamma}$를 바꾸지 않습니다. 따라서 정책 경사와 최적 정책도 바뀌지 않습니다.

$\Psi$를 $V$로 두면 $widetilde{r}$이 곧 $\delta_t^V$가 됩니다.

$$\sum_{l=0}^{\infty}(\gamma\lambda)^l \tilde{r}(s_{t+l}, a_t, s_{t+l+1}) = \hat{A}_t^{\mathrm{GAE}(\gamma,\lambda)} \tag{21}$$

따라서 GAE는 V로 shaping한 보상을 원래 $\gamma$보다 가파른 $\gamma\lambda$로 할인한 합입니다.

### Response function

$$\chi(l; s_t, a_t) = \mathbb{E}[r_{t+l} \mid s_t, a_t] - \mathbb{E}[r_{t+l} \mid s_t]$$

$$A^{\pi,\gamma}(s,a) = \sum_{l=0}^{\infty}\gamma^l \chi(l; s, a)$$

응답함수 $\chi(l;s_t,a_t)$는 $a_t$가 $l$스텝 뒤의 보상에 얼마나 영향을 미치는지 정의합니다. 그리고 advantage function을 
timestep에 대해서 분해합니다. 이는 credit assignment문제를 수치화합니다.

$$g^\gamma = \mathbb{E}\left[\sum_{t=0}^{\infty}\nabla_\theta \log \pi_\theta(a_t \mid s_t)\sum_{l=0}^{\infty}\gamma^l \chi(l; s_t, a_t)\right]$$

만약 $\gamma\lt 1$ 이라면 $l\gg 1/(1-\gamma)$인 항들을 버리는 효과를 만들어냅니다. 버려진 항들의 값이 0이 아니라면 오차가 발생하는데 
$\chi$가 빠르게 감소하면 오차가 줄어듭니다.

만약 $\Psi = V^{\pi,\gamma}$라면 $l>0$일 때 $$\mathbb{E}\left[\widetilde{r}_{t+1} \mid s_t, a_t\right] = \mathbb{E}\left[\widetilde{r}_{t+1} \mid s_t\right] = 0$$입니다. 그리고 응답 함수(response function)는 $l=0$일 때만 0이 아닌 값을 가집니다.

따라서 위에서 적용한 변환이 즉각적인 반응($l$이 0일 때 즉각적인 반응)을 하도록 바꾼 것입니다.
그래서 $V^{\pi,\gamma}$를 잘 추정할 수록 응답함수가 즉각적인 반응을 할 것이라고 기대할 수 있습니다.

따라서 그냥 γ만 쓸 때보다 더 가파른 할인인 γλ를 써서 보상의 지연으로부터 오는 노이즈를 잘라냅니다.
